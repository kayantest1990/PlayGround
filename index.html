      Relay — Chat Server App

      Zero-dependency realtime chat. One server.js (Node built-ins only) serves this UI and provides a JSON + SSE chat API.

      • GET /api/health — server status
      • GET /api/rooms — list rooms
      • GET /api/messages?room=name&since=id
      • POST /api/messages {room, user, text}
      • GET /api/events?room=name — SSE live stream
      • POST /api/typing {room, user}

      Run locally: node server.js then open http://localhost:3000. Without a server, the app runs in local mode (multi-tab sync via BroadcastChannel + localStorage).
